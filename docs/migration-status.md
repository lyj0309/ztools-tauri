# Electron 到 Tauri 2 迁移状态

> 本页记录当前可验证实现，不代表核心迁移完成。完整范围和退出条件以[核心功能迁移方案](core-migration-plan.md)为准。

前七项是独立桌面宿主的已完成范围；第八项开始接入无 Node 插件运行时和市场。

| 3. 存储与配置 | 完成 | SQLite 接管宿主数据；LMDB v1/v2 只读导入 | 自动生成真实 v2 `data.mdb`，设置/收藏/历史/本地项导入且源库不变 |
| 4. 启动器核心 | 完成 | 三平台扫描、启动、拼音搜索、历史、收藏、本地项、后台重扫 | Linux Desktop Entry 单测及开发态搜索/拼音检索通过 |

## 当前尚未实现的旧模块

| 模块 | 原因 |
| --- | --- |
| 插件运行时剩余能力 | `list/none` 后台任务、基础子窗口与父子消息、崩溃恢复尚未完成 |
| 核心插件 API | 图片/文件剪贴板、消息对话框、基础子窗口以及 `onMainPush` 的实际消息源仍待实现 |
| 插件市场剩余能力 | 浏览、分类、搜索、详情元数据、进度/取消、哈希留档、安装升级和卸载已完成；市场没有发布者签名或可信摘要时只能留档，不能声称完成来源验签 |
| 超级面板与悬浮球 | 主要用于发现和执行插件 feature；脱离插件容器没有完整业务对象 |
| 官方账号、AI、支付、MCP、zbrowser | 与官方服务和插件权限体系耦合；新宿主使用无账号凭据的共享目录同步 |
| 插件窗口 API | 当前窗口的尺寸、位置、居中、置顶、最小化、最大化和全屏已实现；子窗口仍未完成，完整 Electron 代理不在核心范围 |
| 图片/文件剪贴板指令匹配 | 当前只有文本历史，图片和文件捕获、展示与回写仍待完成 |
| 旧插件数据迁移 | LMDB 导入器目前只迁移宿主设置、收藏、历史和本地启动项，尚未迁移旧插件数据库与附件 |

## 发布前外部条件

- Windows 和 macOS 的扫描、启动、截图与输入分支需要在各自系统上完成签名环境的最终冒烟测试；当前实际桌面验证在 Linux/X11 完成。
- 自动更新安装需要真实发布地址、minisign 公钥和由 CI 生成的签名更新包。本仓库已实现检查、验签、下载、安装和重启路径，不内置私钥或虚构发布源。
